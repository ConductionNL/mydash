# Tasks — quicklinks-widget

## Tasks

- [ ] Task 1: Create `src/components/Widgets/Renderers/QuicklinksWidget.vue` with a `<div>` root rendering either an empty state (when `links: []`) or a grid/flex layout of link tiles
- [ ] Task 2: Implement empty state rendering with centred message `t('mydash', 'No quicklinks yet — click the gear icon to add some.')` and a clickable gear icon that emits an edit event
- [ ] Task 3: Implement layout wrapper styles (`width:100%; height:100%; display:flex; flex-wrap:wrap; gap:12px; padding:12px`) for flex-wrap mode, and conditional CSS Grid styles when `columns` is a number (not 'auto')
- [ ] Task 4: Implement link tile rendering with icon container (sized per `iconSize` field mapping to 32/48/64/96px) and shaped per `iconShape` (square/rounded/circle with matching border-radius); use `<img>` for custom URLs, `<IconRenderer>` for MDI names, fallback to MDI `link` for empty
- [ ] Task 5: Implement label rendering logic: when `showLabels: true` and `labelPosition: 'below'`, display label below icon; when `labelPosition: 'overlay'`, hide label by default and show on hover/focus; truncate to 20 chars and wrap
- [ ] Task 6: Implement `tileBackgroundStyle` rendering (`transparent` = no background, `solid` = CSS color background, `gradient` = CSS gradient); apply to tile container, respecting shape visibility per REQ-QLNK-004
- [ ] Task 7: Implement hover effects in `<style scoped>`: `lift` = `transform: translateY(-2px)` + `box-shadow`, `fade` = sibling opacity reduction to 0.6, `border` = 2-3px border on hover, `none` = no effect; all with ~150-200ms transitions
- [ ] Task 8: Implement click handler on each `<a>` element: auto-detect `openInNewTab` (true for `http(s)://`, false for `/`), suppress navigation in edit mode (canEdit: true), use `window.open(..., '_blank', 'noopener,noreferrer')` for new tab or `router.push()` for same-tab
- [ ] Task 9: Implement keyboard and accessibility: every link is `<a>` with `href`, `aria-label` (use visible label if available, else hostname), `target="_blank" rel="noopener noreferrer"` for new-tab links; focus indicators visible and WCAG AA compliant
- [ ] Task 10: Implement invalid column value fallback: if `columns` is not `'auto'` or a number `1..12`, default to `'auto'` and log optional console warning
- [ ] Task 11: Create `src/components/Widgets/Forms/QuicklinksForm.vue` with six control sections: (1) links table with columns for label, URL, icon picker; (2) iconSize select (small/medium/large/xlarge); (3) iconShape select (square/rounded/circle); (4) showLabels toggle; (5) labelPosition select (below/overlay); (6) columns input (auto or 1-12); (7) tileBackgroundStyle select (transparent/solid/gradient); (8) hoverEffect select (lift/fade/border/none)
- [ ] Task 12: Implement links table with add/remove row buttons; pre-fill from `editingWidget.content.links` in edit mode; emit `update:content` on every change
- [ ] Task 13: Implement CSV paste handler for links table: parse `label,url,icon[,color]` lines, skip lines with fewer than 2 fields, auto-assign `openInNewTab: true` for external URLs, `false` for internal
- [ ] Task 14: Implement form-level `validate()` method returning errors for: (1) empty URL fields, (2) invalid URL format (tested client-side only; server-side validation is final), (3) empty label when form is required; return `[]` if valid
- [ ] Task 15: Implement client-side URL validation UI: inline check for dangerous protocols (`javascript:`, `data:`, `vbscript:`), URL length <= 2048, valid scheme (`http://`, `https://`, `/`); show red border + error text on invalid field
- [ ] Task 16: Register `quicklinks` in `src/constants/widgetRegistry.js` with `renderer: QuicklinksWidget`, `form: QuicklinksForm`, `defaultContent: {links: [], iconSize: 'medium', iconShape: 'rounded', showLabels: true, labelPosition: 'below', columns: 'auto', tileBackgroundStyle: 'transparent', hoverEffect: 'lift'}`, icon, `displayName: t('mydash','Quicklinks')`, and `gridWidth: 4, gridHeight: 2`
- [ ] Task 17: Translations — add keys to `src/l10n/en.json`: `Quicklinks`, `No quicklinks yet — click the gear icon to add some.`, `Add link`, `Remove link`, `Label`, `URL`, `Icon`, `Color`, `Icon Size`, `Icon Shape`, `Show Labels`, `Label Position`, `Columns`, `Tile Background`, `Hover Effect`, `Invalid URL`, `Link (fallback)`, `Below`, `Overlay`, `Transparent`, `Solid`, `Gradient`, `Lift`, `Fade`, `Border`, `None`, `Auto`
- [ ] Task 18: Dutch translations (`src/l10n/nl.json`): `Snelkoppelingen`, `Nog geen snelkoppelingen — klik op het tandwielpictogram om er enkele toe te voegen.`, `Koppeling toevoegen`, `Koppeling verwijderen`, `Label`, `URL`, `Pictogram`, `Kleur`, `Pictogramgrootte`, `Pictogramvorm`, `Labels weergeven`, `Labelpositie`, `Kolommen`, `Tegelachtergrond`, `Hover-effect`, `Ongeldige URL`, `Koppeling (fallback)`, `Eronder`, `Overlay`, `Transparant`, `Effen`, `Verloop`, `Optillen`, `Vervagen`, `Rand`, `Geen`, `Automatisch`

- [ ] Task 20: Vitest renderer tests — (1) empty links shows empty state message and gear icon (REQ-QLNK-011); (2) links render as `<a>` elements with correct `href` and `aria-label` (REQ-QLNK-010); (3) icon sizes map to correct pixel dimensions (REQ-QLNK-004); (4) icon shapes apply correct border-radius (REQ-QLNK-004); (5) label below vs. overlay positioning works (REQ-QLNK-005); (6) columns auto vs. fixed grid layout (REQ-QLNK-006); (7) hover effects apply per-link (REQ-QLNK-007); (8) custom URL icons render as `<img>` (REQ-QLNK-003); (9) MDI icon names render via `<IconRenderer>` (REQ-QLNK-003); (10) fallback link icon appears for empty icon (REQ-QLNK-003); (11) tile background styles apply (REQ-QLNK-002); (12) invalid column values fall back to auto (REQ-QLNK-006)

## Verification

`openspec validate` exits clean. Quicklinks rendering preserves XSS safety (URL validation blocks dangerous protocols); add/edit round-trip preserves all eight configuration fields; empty state renders correctly and opens edit form on icon click.
